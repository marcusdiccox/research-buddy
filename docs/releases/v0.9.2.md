Fixes Pip disappearing behind other apps on Windows even with **Always on top** enabled.

- Ctrl + Alt + P still shows or hides Pip, with the same entrance animation.
- Showing Pip and changing settings now explicitly restore the correct native window level.
- Turning **Always on top** off still lets ordinary windows cover Pip.

The regression reproduced a visible native window incorrectly reporting that it was not above other windows. The fix passed that test, all 10 pet desktop tests locally, and the full hosted Windows suite: 235 backend tests and 55 desktop tests. The installer and update metadata were verified before publication.
