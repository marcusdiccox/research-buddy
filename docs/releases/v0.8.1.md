Pip 0.8.1 brings automatic notebook backups to the Windows installer.

- Creates a verified local SQLite snapshot on startup and checks every 30 minutes while Pip runs, at most once per UTC date.
- Keeps seven daily snapshots covering notes, reminders, settings and notebook history.
- Includes recent committed database writes and checks snapshot integrity before rotating older backups.
- A backup error does not stop Pip opening or saving notes.

Download **Pip-Setup-0.8.1.exe** and run it to install or update. Desktop and Start menu shortcuts and the Start with Windows setting are included; upgrading preserves your startup preference.

Backups are stored at `%APPDATA%/Research Buddy/backups/` on this computer. They are unencrypted and do not include Google sign-in credentials. A restore screen and cloud backup are not included. The Windows x64 installer is unsigned.

Verified locally: 217 backend tests, all 44 desktop journeys against the packaged app, and integrity checks for all 4,749 archive files. The settings test now waits for asynchronous saved checkbox state rather than requiring an immediate native toggle.
