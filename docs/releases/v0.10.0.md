Pip gets quick capture, more playful interactions, a Today bubble, a No jokes option, and its first Mac build.

- **Quick capture:** select text and press **Ctrl+Alt+N** on Windows or **Command+Option+N** on Mac. Review it in Pip's note bubble before saving. **Capture copied text** in the tray is a fallback. Capture appends to an unsaved note, starts a new note after saving, and preserves a separate unsaved reminder. It runs locally. Windows uses ordinary Copy, so it can replace clipboard contents; Mac reads the accessible selected text.
- **Give treat / Toss ball:** right-click Pip for short animal-specific reactions and small treat, heart and ball animations. Sleeping pets wake first; hiding, dragging or urgent reminders cancel the interaction. Reduced motion uses a static reaction.
- **Today:** a compact view of overdue/today reminders and recent notes. Complete repeating reminders using the existing schedule, jump into an item, or start a note. The first ordinary opening of each local day shows Today; quick capture still opens Notes directly. Windows startup does not automatically open Today.
- **No jokes:** choose it in Settings to turn off casual speech. Event reminders and other useful messages still work.
- **Mac:** universal DMG and ZIP for Apple silicon and Intel, plus an **Open at login** setting. Drag Research Buddy into Applications. Selection copying requires macOS Accessibility permission; the copied-text fallback remains available. This first Mac build is ad-hoc signed and not notarized; Mac updates are manual through the Settings update button. Windows automatic updates remain enabled.

The Mac packages are built and checked on a macOS runner. Physical Mac testing and Developer ID signing/notarization are not included in this release. Windows installer remains unsigned.
