Focus gets its own small, movable timer card.

- Starting a focus session opens an ivory-and-sage floating countdown with a quiet progress ring, without taking focus from your notes.
- Drag the card anywhere. Its pin appears on hover or keyboard focus and keeps the timer above other windows. Pin state is separate from note pinning.
- Hide the timer without stopping the session. Restore it with the pop-out icon beside the inline timer or **Focus timer** in the tray menu.
- Stop from either surface, or finish to see **Nice work.** The existing 15/25/45-minute choices, quiet pet behavior and urgent reminders still work.
- The note bubble's pin now uses the same hover/focus reveal.

Includes Windows scaling fixes for repeated show/hide, a reliable native stacking level, unfocused transparent-window painting and final-position handling for very quick drags. The updater remains compatible with 0.9.0; download automatically and install when you quit Pip. Windows x64 installer remains unsigned.
